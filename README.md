#FinTracker

REST API фин-трекер, позволяющий отслеживать личные финансы, а также потренировать Spring Security, Kafka и прочие инструменты, что могут быть полезны/интересны

## Технологический стек

- Java 17, Spring Boot (Spring Secutiry + JWT)
- Hibernate + PostgreSQL
- Kafka, Docker

## Как запустить:

- Клонируйте репозиторий
- В корне проекта запустить docker-compose up -d
